# 문서 형식 작성 예시

`§1`에서 화면 단위 섹션을 작성할 때 참조한다.

---

탭 문서의 **화면 단위 섹션**에 네 덩어리를 붙인다. 기존 내용은 그대로 두고 추가만 한다.

```text
[H2]  피드 리스트
      > IA: Home > Feed | MVP 1 | 무료 O

[H3]  상태
      | 상태   | 조건            | 화면                |
      | 기본   | 데이터 있음     | 카드 리스트         |
      | 빈상태 | 오늘 항목 없음  | 안내 + 대체 동선 CTA |
      | 무료   | 비구독          | 일부 항목 마스킹     |

[H3]  전이
      | 트리거    | 목적지      | 방식      |
      | 카드 탭   | 콘텐츠 본문 | 화면 이동 |
      | 마스킹 탭 | 구독 안내   | 바텀시트  |

[H3]  주석
      1. 필터 — 전체 / 구독 중 / 최근 3일 이내
      2. 조건 충족 카드만 유료 영역 마스킹. 미충족 시 해당 영역 미노출
      3. 상세 딥링크는 임계값 초과 시에만 노출
```

`[H2]`/`[H3]`는 헤딩 레벨 표기이며 실제 문서에는 쓰지 않는다 — `##`, `###`로 작성한다.
