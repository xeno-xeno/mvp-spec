# 게이트 판정 근거

`§0-1` 점검 항목을 정한 근거가 필요할 때 읽는다.

---

## 항목 선택 근거

| 항목 | 넣은 이유 |
|---|---|
| 1 제공할 핵심 서비스와 주 이용자 | 무엇을 누구에게 주는지 모르면 화면의 존재 이유를 판단할 수 없다. 다만 화면 목록 도출을 막지는 않아 진행 차단이 아니다 |
| 2 포지셔닝과 유저 저니 | 유저 저니가 이동 표의 입력이다. 포지셔닝은 보조라 저니만 있어도 충족 |
| 3 메뉴 구성 | 화면 ID의 대메뉴가 여기서 정해진다 |
| 4 기능 우선순위 | 이번 범위와 화면 장수를 정한다 |

**메뉴 구성은 유저 저니에서 파생된다.** 유저 플로우의 주 목적이 정보 구조를 구축하는 것이므로,
3번이 2번 없이 먼저 정해졌다면 그 자체가 검토 대상이다 — 저니 없이 정한 메뉴 구성은 근거가 없다.

**뺀 것**

| 뺀 것 | 이유 |
|---|---|
| 수익모델 · 성공 지표 | 초기 MVP 화면 설계의 입력이 아니다. 필요하면 Master에 자유롭게 쓴다 |
| 무료/유료 구분 (무료 행·BM 검토) | 수익모델을 뺐으므로 다루지 않는다 (`spec_format: 2`) |
| 작업 유형 분기 (신규·고도화·리뉴얼) | 이 스킬은 **초기 서비스 기획 전용**이다. 분기를 없애 질문과 규칙을 줄였다 |

기존 서비스에 기능을 더하는 문서도 같은 4개로 점검한다. 3번은 "기존 메뉴 그대로"라고 한 줄 있으면 충족이다.

---

## Master 승격 판단

`#done` 처리 전에 **화면을 넘나드는 규칙**은 Master로 옮긴다. 옮기지 않으면 기준이 사라진다.

판단 기준: **한 화면에만 적용되면 주석에, 여러 화면에 걸리면 Master에.**

예: 조건 판정 임계값, 강조 기준값, 데이터 보관 기간, 용어 사전.

이들은 여러 화면에 공통 적용되므로, 탭 문서에 남겨두면 그 문서를 닫은 뒤 기준이 사라진다.

---

## 자주 걸리는 패턴

전부 형식은 갖췄는데 내용이 어긋난 경우다. 체크리스트로는 잡히지 않는다.

| 패턴 | 유형 |
|---|---|
| 로그인이 MVP 1순위인데 화면 정의 0개 | 구조 미싱링크 |
| 화면 정의와 진입점이 서로 다른 문서에 흩어짐 | 동선 단절 |
| 복사·붙여넣기로 동일 블록이 중복 | 문서 품질 |
| 우선순위 1 항목의 콘텐츠가 "미정"으로만 표기 | 정의 공백 |

## 문서 수명 운영 상세

탭별 MVP 문서는 **화면 설계를 위한 입력**이다. 생성이 끝나면 역할이 끝나고,
이후 정본은 화면 설계 산출물이다.

```
Master · IA          지속 유지          #live
탭별 MVP 문서         화면 설계까지만     #draft → #ready → #done
화면 설계 산출물      생성 이후 정본
```

| 태그 | 의미 |
|---|---|
| `#draft` | 작성 중 |
| `#ready` | 형식 4덩어리 완료. 화면 설계 대기 |
| `#done` | 생성 완료. **갱신하지 않음** |
| `#live` | 지속 유지 (Master · IA) |

프론트매터에 생성된 화면 ID를 남긴다 — 문서 ↔ 화면 설계 연결이 이 한 줄로 해결된다.

```yaml
tags: [done]
spec_format: 2
screens: Feed-Latest-List-01, Feed-Article-01, Explore-ItemDetail-01
completed: YYYY-MM-DD
```

### Master로 승격할 것

`#done` 처리 전에 **여러 화면에 걸리는 규칙**은 Master로 옮긴다. 판단 기준과 예시는 위
"Master 승격 판단" 참조.

## 판정 깊이 예시

러프하게라도 서술돼 있으면 충족이다. 애매하면 충족 + `(파일·러프)`.

| 문서에 있는 것 | 판정 |
|---|---|
| "탐색 → 항목 선택 → 상세" | **충족** — 저니 순서가 있다 |
| "사용자가 원하는 것을 찾는다" | 미충족 — 순서가 없다 |
| "홈 / 탐색 / 내 모임 / 마이" | **충족** — 메뉴가 있다 |
| "메뉴는 나중에 정함" | 미충족 — 메뉴가 없다 |
| "1순위: 검색, 신청. 2순위: 알림" | **충족** — 우선순위가 있다 |

## 선행 작업 질의 범위

| 게이트 단계에서 묻는 것 | 묻지 않는 것 (§2·§3의 몫) |
|---|---|
| 서비스 한 줄과 주 이용자 | 페르소나 상세 |
| 핵심 시나리오 2~3개의 순서 | 각 단계의 화면 구성 |
| 메뉴 후보 영역 | 서브탭 구성·화면 장수 |
| 1순위 기능 목록 | 각 기능의 상태 분기 |
