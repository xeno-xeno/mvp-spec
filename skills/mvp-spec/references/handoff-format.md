# 출력 계약 — spec_format: 2

이 스킬이 내는 **갱신본 문서의 형식 계약**이다. 화면 설계 단계(사람이든 도구든)는 이 계약만
전제로 읽는다. 형식을 바꾸면 하위 도구가 깨질 수 있으므로 버전을 둔다.

---

## 1. 프론트매터

```yaml
---
spec_format: 2                  # 이 계약의 버전. 필수
tags: [ready]                   # draft | ready | done | live
screens: Feed-Latest-List-01, Feed-Article-01   # 이 문서가 정의하는 화면 ID(가ID). 필수
updated: YYYY-MM-DD
---
```

## 2. 화면 목록 표 — 문서 상단에 1개 (H1 제목과 그 아래 인용줄 다음)

| 화면 ID | 화면 | 레벨 | 진입 | MVP | 상태 수 |
|---|---|---|---|---|---|

| 칸 | 허용 값 |
|---|---|
| 레벨 | `Home` / `Main` / `Detail` / `기능형` |
| MVP | `1` / `2` / `3` — 장수 상한은 `1`만 센다 |
| 상태 수 | 해당 화면 상태 표의 행 수 |
| 진입 | 이 화면으로 들어오는 화면 ID 목록. 앱 첫 화면·GNB는 `앱 시작`·`GNB`로, 다른 문서나 외부에서 들어오면 `푸시`·`딥링크`처럼 적는다 |

## 3. 화면 섹션 — 화면마다 1개, 순서 고정

```
## {화면 ID} — {화면명}
> IA: {경로} | MVP {n}

### 상태
| 상태 | 조건 | 화면 |

### 이동
| 트리거 | 목적지 | 방식 |

### 주석
1. ...
2. ...

[미결]                       ← 선택. 있으면 주석 블록 끝
· ...
```

### 칸 규칙

| 칸 | 허용 값 |
|---|---|
| 상태 행 | `기본` · `빈상태` **필수**. 추가 상태(예: `확장`, `한도초과`) 허용 |
| IA 참조줄 | IA 문서가 없으면 메뉴 구성의 경로를 쓴다 |
| 이동 `목적지` | 화면 ID, `같은 화면 내`, `뒤로`. 목록에 없는 대상은 이름 + `※ 미정의` |
| 이동 `방식` | `화면 이동` / `모달` / `바텀시트` / `같은 화면 내` / `뒤로` |
| 주석 | 번호 목록. 한 줄 38자 권장, 넘으면 다음 줄을 5칸 들여 쓴다 |
| `[미결]` | `·` 목록. 이어지는 줄은 2칸 들여 쓴다. 문서에 정의가 없는 칸은 `[미결] 정의 없음`, 상위 근거 없이 대체한 값은 `상위 근거 없음`으로 표기 |

## 4. 하위 단계가 기대해도 되는 것 · 안 되는 것

| 기대해도 됨 | 기대하면 안 됨 |
|---|---|
| 위 구조와 허용 값 | 레이아웃·카피의 확정 — 문서는 정의 수준이다 |
| 이동 목적지가 화면 ID이거나 `※ 미정의` 표시가 붙어 있음 | 상태 수만큼의 화면 장수 — 상태 수는 **상한**이다. 상태는 별도 화면을 만들지 않는다 |
| 모든 화면에 `기본`·`빈상태` 행이 있음 | 화면 ID가 최종값 — 가ID이며 화면 설계 단계에서 확정된다 |

## 5. 버전 규칙

| 변경 | 버전 |
|---|---|
| 선택 칸 추가 | 유지 |
| 칸 이름·순서·허용 값 변경, 필수 칸 추가·삭제 | `spec_format` +1 |

- 하위 도구는 **모르는 버전**을 받으면 사용자에게 알리고 진행 여부를 묻는다
- `spec_format: 1` 문서는 `무료` 상태 행, IA 참조줄의 권한 값, `work_type`을 **무시**하고 읽고, `### 전이`는 `### 이동`으로 읽는다
- `spec_format`이 없는 문서는 **계약 이전 문서(v0)**로 본다. 하위 도구는 서술에서 판단하고
  그 사실을 리포트에 적는다

### 변경 이력

| 버전 | 변경 |
|---|---|
| 2 | 상태 행 `무료` 삭제(필수 → 없음), 무료 행 유형 삭제, IA 참조줄의 권한 칸 삭제, 프론트매터 `work_type` 삭제, 섹션 이름 `전이` → `이동` |
| 1 | 최초 |
